# Labs

These directories hold lab instructions and starter files. Students fork the
whole course and complete each lab in its existing directory on a separate
branch. Follow the [student workflow](../docs/student-workflow.md) to set up
instructor review and submit a PR to `master` in your own fork.

Lab 01 deliberately uses manual build and deployment commands; later labs
may introduce Makefiles. Commit source and documentation, but not generated
binaries. Complete the lab's `report.md` with the requested evidence. The shared
kernel workspace lives outside the course and its forks; see the
[workspace guide](../docs/course-workspace.md).
