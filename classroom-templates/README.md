# Labs

These self-contained templates can become separate GitHub Classroom assignment
repositories. Each lab is self-contained: its directory holds the instructions and starter
code. Lab 01 deliberately uses manual build and deployment commands; later labs
may introduce Makefiles. Commit source and documentation, but not generated
binaries. Complete the lab's `report.md` with the requested evidence. The shared
kernel workspace lives outside each lab repository; see the
[workspace guide](../docs/course-workspace.md).
